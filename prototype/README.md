# JobPilot V1.0 低保真原型

打开 [index.html](./index.html) 即可浏览。原型是独立的本地 HTML 文件，无需安装依赖。示例公司与岗位均为虚构；新增、编辑、删除和状态更新只在当前页面内模拟，刷新后恢复示例数据。此文件用于确认交互与布局，不承担正式产品的数据保存。

## 三个页面

| 页面 | 主要操作 | 对应 PRD |
|------|----------|----------|
| 岗位库 | 搜索和筛选岗位；用右侧表单新增、编辑；二次确认删除 | 功能 1 |
| 进度看板 | 按状态查看岗位；用下拉框更新状态；终止状态折叠显示 | 功能 2 |
| 求职总览 | 查看岗位总数、累计投递数、当前面试数及日期事项 | 功能 3 |

## 建议走查路径

1. 在岗位库点击“添加岗位”，只填写公司和岗位名称并保存，确认随手记录的步骤是否足够短。
2. 在进度看板将一条“收藏”岗位直接改为“面试”，确认跳级操作是否符合真实招聘流程。
3. 在求职总览查看累计投递和面试数字，确认两者随状态更新。
4. 点击顶部“查看空状态”，检查三个页面在没有岗位时是否知道下一步怎么做；点击“恢复示例数据”返回。

原型依据 [JobPilot 落地版 PRD](../JobPilot_PRD_V1.0.md) 制作。界面使用蓝色导航、分阶段状态色和日期提示色，仍以页面结构与交互评审为目的；开发时以 PRD 的字段、规则和验收标准为准。
